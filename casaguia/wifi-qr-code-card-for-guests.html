How do I make a Wi-Fi QR code card for guests?

Updated 2026-11-03 · CasaGuía

A Wi-Fi QR code holds the text WIFI:T:WPA;S:<network>;P:<password>;;. iPhone and Android cameras join the network when they scan it, so guests never type the password. Print it on a card near the router or the door.

Steps

  1. Write down the exact network name (SSID) and password; both are case-sensitive.
  2. Generate the QR with an offline tool, so your password is not uploaded anywhere.
  3. Test it with two phones (iPhone and Android) before printing.
  4. Print it with the network name and password also written in text, for laptops.

Tips

  • If you change the password, print the card again.
  • Use WPA2 or WPA3 security. A guest network on the router keeps your own devices separate.
  • Special characters such as ; , : or \ must be escaped with a backslash in the QR text; good generators do this for you.

Quick answers

Can iPhones scan a Wi-Fi QR code?

Yes. Since iOS 11 the Camera app reads Wi-Fi QR codes and offers to join the network. Most Android phones do the same from the camera or the Wi-Fi settings.

Is it safe to put the Wi-Fi password in a QR code?

It is as safe as printing the password: anyone who scans it can join. Use a guest network and change the password between long stays if needed.
